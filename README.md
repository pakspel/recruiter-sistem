# 🎯 Recruiter Rating System

Система рейтинга рекрутов для Discord. Автоматически начисляет баллы при принятии/отклонении заявок, ведёт лидерборд, еженедельно списывает баллы.

---

## 🚀 Деплой на Railway (5 шагов)

### 1. Создай Discord бота

1. Открой https://discord.com/developers/applications
2. **New Application** → дай имя
3. Слева **Bot** → **Reset Token** → скопируй токен
4. Включи: **Message Content Intent**, **Server Members Intent**
5. Слева **OAuth2 → URL Generator** → отметь `bot` и `applications.commands`
6. В разрешениях отметь: **Read Messages**, **Send Messages**, **Embed Links**, **Manage Roles**
7. Скопируй ссылку и добавь бота на сервер

### 2. Залей код на GitHub

```bash
git init
git add .
git commit -m "initial"
git remote add origin https://github.com/ВАШ_НИК/recruiter-system.git
git push -u origin main
```

### 3. Создай проект на Railway

1. Открой https://railway.app
2. **New Project → Deploy from GitHub repo** → выбери репозиторий
3. Railway сам определит Node.js и запустит `npm start`

### 4. Настрой переменные окружения

В Railway: проект → **Variables** → добавь:

| Ключ | Значение |
|------|----------|
| `BOT_TOKEN` | Токен твоего бота |
| `CLIENT_ID` | ID твоего приложения (на странице бота в Dev Portal) |
| `GUILD_ID` | `1441477059955130388` |
| `API_KEY` | Любая секретная строка |

### 5. Готово!

Railway даст тебе ссылку вида `https://xxx.up.railway.app` — это твой лидерборд.

## ⚙️ Discord команды

| Команда | Описание |
|---------|----------|
| `/рейтинг` | Показать таблицу рейтинга |
| `/профиль [@user]` | Профиль рекрута |
| `/добавить_рекрута @user [имя]` | Зарегистрировать рекрута |
| `/убрать_рекрута @user` | Удалить рекрута |
| `/баллы @user +10 причина` | Добавить/снять баллы |
| `/сжечь_баллы` | Провести еженедельное списание вручную |
| `/настройки списание 5` | Изменить еженедельное списание |
| `/настройки канал_бота ID` | ID канала откуда читать другого бота |
| `/настройки id_бота ID` | ID другого бота |
| `/настройки показать` | Текущие настройки |

## 🤖 Интеграция с другим ботом

После деплоя выполни в Discord:

```
/настройки канал_бота ID_КАНАЛА_ЗАЯВОК
/настройки id_бота ID_ДРУГОГО_БОТА
```

Твой бот будет автоматически читать сообщения вида:
- `<@USER> принял заявку в семью от <@USER>. Роль семьи выдана.` → **+5 баллов**
- `<@USER> отклонил заявку от <@USER>.` → **+3 балла** (выявил нарушителя)

## 💎 Система баллов

| Действие | Баллы |
|----------|-------|
| Кандидат принят | +5 |
| Кандидат отклонён (нарушитель) | +3 |
| Кандидат слился после принятия | -3 |
| Ручное начисление | любое |
| Еженедельное списание | -5 |

**Ранги:**
- 🔰 Стажёр — 0–29 баллов
- 🎯 Рекрут — 30–74 балла
- ⚡ Агент — 75–149 баллов
- 👑 Элита — 150+ баллов
