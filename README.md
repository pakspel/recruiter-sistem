## 1. Быстрый старт

### Требования

- Node.js 18+
- Аккаунт [Railway](https://railway.app) (или любой VPS)
- Discord-приложение с ботом

### Локальный запуск

```bash
git clone <репозиторий>
cd recruiter-sistem

npm install

# Скопируй пример .env и заполни
cp .env.example .env

npm start
```

### Создание Discord-бота

1. Открой [Discord Developer Portal](https://discord.com/developers/applications)
2. **New Application** → придумай название
3. Слева → **Bot** → **Add Bot**
4. Скопируй **Token** → `BOT_TOKEN` в `.env`
5. Включи все три **Privileged Gateway Intents**:
   - `PRESENCE INTENT`
   - `SERVER MEMBERS INTENT`
   - `MESSAGE CONTENT INTENT`
6. Слева → **OAuth2 → URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: `Send Messages`, `Read Message History`, `Add Reactions`, `Embed Links`, `Read Messages/View Channels`, `Manage Messages`
7. Открой сгенерированную ссылку → добавь бота на сервер

## 2. Переменные окружения

Скопируй `.env.example` в `.env` и заполни все поля.

```env
# ── Discord Bot ───────────────────────────────────────────
BOT_TOKEN=              # Токен бота из Developer Portal → Bot
CLIENT_ID=              # Application ID из General Information
GUILD_ID=               # ID твоего Discord-сервера (ПКМ по серверу → Копировать ID)

# ── Безопасность ──────────────────────────────────────────
API_KEY=                # Произвольный секретный ключ для внутреннего API бота
                        # Придумай сам: например, сгенерируй через openssl rand -hex 32

# ── Суперадмин сайта ──────────────────────────────────────
SUPER_ADMIN_LOGIN=      # Логин суперадмина на сайте
SUPER_ADMIN_PASSWORD=   # Пароль суперадмина (минимум 6 символов)
                        # ⚠️ Не коммить .env в репозиторий!

# ── Роли ──────────────────────────────────────────────────
ADMIN_ROLE_ID=          # ID роли администратора в Discord
                        # (ПКМ по роли в настройках сервера → Копировать ID)
CURATOR_ROLE_ID=        # ID роли куратора (опционально)
                        # Если не задан — куратором считается тот, у кого ≥2000 баллов

# ── База данных ────────────────────────────────────────────
DATA_PATH=./data.db     # Путь к SQLite-файлу
                        # На Railway: /data/recruiter.db (нужен Volume)

# ── Сервер ────────────────────────────────────────────────
PORT=3000               # Railway выставляет сам — не трогай
SITE_URL=               # Публичный URL сайта (например, https://my-app.railway.app)
                        # Используется в DM-сообщениях рекрутам
```

> **Где взять ID?** Включи режим разработчика в Discord: **Настройки → Дополнительно → Режим разработчика**. После этого ПКМ на любом элементе даёт пункт «Копировать ID».

## 3. Деплой на Railway

1. Зарегистрируйся на [railway.app](https://railway.app)
2. **New Project → Deploy from GitHub repo** → выбери репозиторий
3. Railway автоматически определит Node.js и запустит `node index.js`

### Настройка Volume (постоянная база данных)

Без Volume база данных сбрасывается при каждом деплое.

1. В проекте Railway → **+ New** → **Volume**
2. Mount Path: `/data`
3. В переменных окружения установи: `DATA_PATH=/data/recruiter.db`

### Переменные окружения в Railway

**Variables** → добавь все переменные из таблицы выше по одной.

## 4. Первичная настройка через бота

После запуска выполни эти команды в Discord **один раз**.

### Шаг 1 — Настрой каналы

```
/настройки канал_бота      id:<ID канала другого бота>
/настройки id_бота         id:<ID другого бота>
/настройки канал_отчётности id:<ID канала где рекруты пишут отчёты>
/настройки канал_проверки  id:<ID канала куда бот присылает логи для тебя>
```

> Канал проверки — закрытый канал только для администраторов. Там появляются все отчёты рекрутов для проверки.

### Шаг 2 — Настрой баллы за отчёты

```
/настройки баллы_за_отчёт  кейворд:ТП     баллы:5
/настройки баллы_за_отчёт  кейворд:ВН     баллы:5
/настройки баллы_за_отчёт  кейворд:5ВИТО  баллы:5
```

> Кейворд `ЗАДАНИЕ` встроен отдельно — баллы за него куратор выставляет вручную.

### Шаг 3 — Настрой списание

```
/настройки списание баллы:5
```

### Шаг 4 — Проверь настройки

```
/настройки показать
```

|---|---|

| `/профиль` | Показать свой профиль (баллы, ранг, история) |
| `/профиль пользователь:@кто-то` | Профиль другого рекрута |
| `/задания` | Показать список своих заданий с кнопками выполнения |
| `/привязать` | Получить одноразовый код для привязки Discord к сайту |

### Команды для администраторов

> Требуют роль `ADMIN_ROLE_ID` или права `Manage Roles`.

| Команда | Описание |
|---|---|
| `/добавить_рекрута пользователь:@кто-то` | Добавить рекрута в систему. Автоматически создаёт аккаунт на сайте и отправляет данные в ЛС |
| `/добавить_рекрута пользователь:@кто-то имя:Имя` | То же, но с кастомным отображаемым именем |
| `/убрать_рекрута пользователь:@кто-то` | Удалить рекрута из системы |
| `/баллы пользователь:@кто-то количество:10` | Добавить баллы вручную |
| `/баллы пользователь:@кто-то количество:-5 причина:Нарушение` | Снять баллы с указанием причины |
| `/сжечь_баллы` | Провести еженедельное списание вручную (обычно не нужно — работает по расписанию) |

### Команды настройки (только администраторы)

| Команда | Описание |

| `/настройки id_бота id:123` | ID другого бота (для авто-начисления за кандидатов) |
| `/настройки канал_отчётности id:123` | Канал где рекруты присылают отчёты |
| `/настройки канал_проверки id:123` | Канал куда бот присылает логи для проверки |

## 6. Система отчётности

Рекруты отправляют отчёты в специальный канал. Бот автоматически обрабатывает их.

### Формат отчёта

```
@Dep.REC | ORG | Имя | Ник  КЕЙВОРД
[скриншот]
```

**Пример:**
```
@Dep.REC | ORG | Tony | Вячеслав  ВН
[прикреплён скриншот]
```

> ⚠️ **Без скриншота баллы не начисляются** — бот пришлёт ошибку и удалит её через 30 секунд.

### Кейворды и их обработка

| Кейворд | Баллы | Логика |
|---|---|---|
| `ТП` | настраивается | Баллы начисляются **сразу автоматически** |
| `ВН` | настраивается | Баллы начисляются **сразу автоматически** |
| `5ВИТО` | настраивается | Баллы начисляются **сразу автоматически** |
| `ЗАДАНИЕ` | куратор вводит сам | Баллы **ждут оценки** куратора |

Кейворды можно добавлять любые через `/настройки баллы_за_отчёт`.

### Что видит рекрут

- ✅ — баллы начислены (или задание принято)
- ⏳ — задание ждёт оценки куратора
- ❌ — отчёт отклонён как скам

### Что видит администратор (канал проверки)

**Обычный кейворд (ТП / ВН / 5ВИТО):**

Бот присылает embed с информацией и одной кнопкой:
- `❌ Скам — снять N баллов` — если отчёт поддельный, нажми и баллы снимутся автоматически

**Кейворд ЗАДАНИЕ:**

Бот присылает embed с кнопками:
- `💎 Выставить баллы` — открывает окно ввода числа (1–500). Доступно кураторам и администраторам
- `❌ Отклонить` — отклонить без начисления

### Авто-начисление за другого бота

Если на сервере есть бот рекрутинга, который пишет сообщения вида:
```
<@рекрутёр> принял заявку в семью от <@кандидат>
<@рекрутёр> отклонил заявку от <@кандидат>
```

Укажи его канал и ID через `/настройки канал_бота` и `/настройки id_бота` — баллы будут начисляться автоматически.

## 7. Веб-сайт — страницы

| Страница | URL | Доступ |
|---|---|---|
| Рейтинг рекрутов | `/` или `/index.html` | Все |
| Личный кабинет | `/cabinet.html` | Авторизованные |
| История баллов | `/history.html` | Администраторы |
| Суперадмин | `/superadmin.html` | Только суперадмин |

### Рейтинг (`/`)

Главная страница. Показывает таблицу всех рекрутов с баллами, рангами, статусами и активностью по неделям. Обновляется каждые 30 секунд.

**Фильтры:** Все / Активные / Предупреждение / Опасность / Кураторы

**Кнопки для администраторов** (видны только после входа):
- `⚙ АДМИН` — панель управления
- `👤 ЛК РЕКРУТА` — личный кабинет
- `📜 ЛОГИ БАЛЛОВ` — история всех начислений

**Панель администратора** (кнопка ⚙ АДМИН):
- **Заявки** — одобрение/отклонение заявок на регистрацию
- **Рекруты** — добавление по Discord ID, переименование, список
- **Задания** — создание заданий, список с возможностью раскрыть кто выполнил

### Личный кабинет (`/cabinet.html`)

Страница рекрута. Показывает профиль, историю баллов, активные задания и форму привязки Discord.

### История баллов (`/history.html`)

Полный лог всех начислений и списаний по всем рекрутам. Доступен только администраторам.

### Суперадмин (`/superadmin.html`)

Управление аккаунтами: смена ролей пользователей (recruiter → admin и обратно). Доступен только суперадмину.

## 8. Ранги и статусы

### Ранги (по количеству баллов)

| Ранг | Значок | Минимум баллов |
|---|---|---|
| Стажёр | 🔰 | 0 |
| Рекрут | 🎯 | 30 |
| Агент | ⚡ | 75 |
| Элита | 👑 | 150 |
| Куратор | 🛡 | 2 000 |

> Рекруты с 2 000+ баллов становятся Кураторами. Кураторы **не теряют баллы** при еженедельном списании.

### Статусы

| Статус | Цвет | Условие |
|---|---|---|
| 🟢 Активен | Зелёный | Баллы > 10 |
| 🟡 Предупреждение | Жёлтый | Баллы 6–10 |
| 🔴 Опасность | Красный | Баллы 1–5 |
| 💀 Удалён | — | Баллы = 0 |

## 9. Еженедельное списание

Каждую неделю у всех рекрутов (кроме Кураторов) автоматически списывается `weeklyBurn` баллов (по умолчанию 5).

**Как работает:**
1. У рекрута снимается N баллов
2. Если баллы упали до 0 — статус меняется на «Удалён»
3. Бот публикует сообщение с результатами: кто в опасности, кто удалён
4. Активность за неделю фиксируется (заработал ли рекрут хоть что-то)

**Расписание:** каждый понедельник в 12:00 (UTC). Можно запустить вручную: `/сжечь_баллы`.

**Изменить количество:** `/настройки списание баллы:10`

## 10. Роли и права доступа

| Роль | Где настраивается | Возможности |
|---|---|---|
| Все | — | `/рейтинг`, `/профиль`, `/задания`, `/привязать` |
| Администратор | `ADMIN_ROLE_ID` в `.env` | Все команды бота, панель на сайте, история баллов |
| Куратор | `CURATOR_ROLE_ID` или ≥2000 баллов | Выставление баллов за ЗАДАНИЕ |
| Суперадмин | `SUPER_ADMIN_LOGIN` в `.env` | Смена ролей пользователей сайта |

> Суперадмин — это роль на **сайте**, а не в Discord. Она позволяет назначать других администраторов через `/superadmin.html`.

## 11. Привязка Discord к сайту

Привязка нужна для доступа к заданиям через команду `/задания` в Discord.

### Для рекрута

1. Войди в личный кабинет на сайте (данные пришли в ЛС при добавлении)
2. Напиши в Discord: `/привязать`
3. Бот пришлёт **одноразовый код** в личные сообщения (действует 5 минут)
4. Введи код в личном кабинете → раздел **🔗 Привязка Discord**

### Для администратора

При добавлении рекрута через `/добавить_рекрута` привязка происходит **автоматически** — рекруту сразу отправляется ЛС с логином, паролем и готовой привязкой Discord.

## Частые вопросы

**Бот не реагирует на отчёты**
→ Проверь, что канал отчётности настроен: `/настройки показать`

**Рекрут не получил ЛС при добавлении**
→ У него закрыты личные сообщения. Передай данные вручную — бот покажет их тебе в ответе на команду (видно только тебе).

**Задание не показывается в `/задания`**
→ Рекрут не привязал Discord к сайту. Пусть выполнит инструкцию из раздела 11.

**Как добавить новый кейворд?**
→ `/настройки баллы_за_отчёт кейворд:НОВЫЙ баллы:7`

**Как сменить пароль суперадмина?**
→ Обнови `SUPER_ADMIN_PASSWORD` в переменных окружения и перезапусти сервер.

**База данных сбрасывается после деплоя**
→ Настрой Volume в Railway и укажи `DATA_PATH=/data/recruiter.db`.
