# 🎯 Recruiter System

Система рейтинга рекрутов с Discord-ботом и веб-панелью.

---

## 🛠 Установка

```bash
npm install
cp .env.example .env
# заполни .env
node index.js
```

---

## 🗄 База данных (SQLite)

Данные хранятся в SQLite-файле — **больше не теряются при редеплое**.

| Переменная  | Описание                            | Пример              |
|-------------|-------------------------------------|---------------------|
| `DATA_PATH` | Путь к файлу базы данных            | `/data/recruiter.db`|

### Railway — как сохранить данные навсегда

1. В Railway: **Add Volume** → путь монтирования `/data`
2. В настройках переменных окружения: `DATA_PATH=/data/recruiter.db`
3. Готово — данные живут в Volume и не удаляются при деплое

---

## 🔒 Исправленные баги

- **Рекруты больше не могут накручивать/убирать себе баллы через сайт.**  
  Кнопка редактирования баллов теперь видна только администраторам.  
  Эндпоинт `/api/points` проверяет роль — рекруты получают `403 Forbidden`.

## 👤 Аккаунт суперадмина

При старте сервера автоматически создаётся аккаунт:

- **Логин:** `PAKSPEL`
- **Пароль:** из `index.js` (строка `storage.seedAdmin(...)`)

> Смени пароль через «Личный кабинет → Сменить пароль»

---

## ⚡ Суперадмин-панель (только PAKSPEL)

Открывается по адресу: **`/superadmin.html`**

Возможности:
- Просмотр всех зарегистрированных пользователей
- Смена роли: `Рекрут ↔ Администратор`
- Статистика: сколько всего, админов, рекрутов
- Поиск по логину

> Страница недоступна для всех, кроме PAKSPEL — ни фронтенд, ни бэкенд не пропустят.

## 🔌 API

| Метод  | Путь                                   | Доступ        |
|--------|----------------------------------------|---------------|
| POST   | `/api/auth/register`                   | Все           |
| POST   | `/api/auth/login`                      | Все           |
| GET    | `/api/auth/me`                         | Токен         |
| POST   | `/api/auth/change-password`            | Токен         |
| GET    | `/api/leaderboard`                     | Все           |
| POST   | `/api/points`                          | **Только админ** или API-ключ |
| GET    | `/api/admin/pending`                   | Админ         |
| POST   | `/api/admin/approve`                   | Админ         |
| POST   | `/api/admin/reject`                    | Админ         |
| GET    | `/api/admin/tasks`                     | Админ         |
| POST   | `/api/admin/tasks`                     | Админ         |
| DELETE | `/api/admin/tasks/:id`                 | Админ         |
| GET    | `/api/superadmin/users`                | **Только PAKSPEL** |
| POST   | `/api/superadmin/users/:login/role`    | **Только PAKSPEL** |

## 💡 Идеи для развития

- **История изменений баллов** — отдельная страница с фильтром по рекруту/дате
- **Уведомления в Discord** — при смене ранга бот пишет рекруту в ЛС
- **Сезоны** — обнуление баллов по расписанию с сохранением архива
- **Достижения** — бейджи за «первый принятый», «10 принятых подряд» и т.д.
- **График активности** — визуализация баллов за последние N недель
- **Экспорт** — выгрузка таблицы рекрутов в CSV одной кнопкой
